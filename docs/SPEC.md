# אפיון – אפליקציית ישיבת שדרות

## 1. משתמשים והרשאות
- **תלמיד:** צפייה, פרסום מודעות, הזמנות.
- **רב / מגיד שיעור:** ניהול הכיתה שלו (סיכומים והודעות).
- **ראש ישיבה / הנהלה:** סדר יום, פרשת שבוע, אירועים, אישור משתמשים.
- **אדמין:** ניהול כל המערכת.

## 2. הרשמה ואימות
- שדות: שם מלא, טלפון (אימות OTP), רב (מרשימה), שיעור (א'–ד'), תעודת זהות.
- אימות מול רשימת תלמידים מראש או אישור ידני של הנהלה. עד האישור המשתמש במצב "ממתין".
- ת"ז נשמרת כ-hash בלבד. אין שמירה של המספר המלא.

## 3. מסכים
בית · סדר יום · זמני היום · לוח מודעות (אבידה, טרמפים, החלפת ספרים, כללי) · אוצר הספרים (קטלוג, מבצעים, הזמנה) · לוח שנה (שבת ישיבה / חופשית, אירועים, חגים) · פרשת שבוע (PDF/טקסט, העלאה להנהלה בלבד) · כיתות (שיעור ← רב; סיכומים והודעות) · ראש הישיבה · פרופיל.

## 4. תוספות מוצעות
התראות Push · שיעורי אודיו · "שאל את הרב" · הרשמה לשבת · מצב חירום/צבע אדום · סקרים · דף יומי · מצב כהה.

## 5. ארכיטקטורה
- **MVP (קיים):** React + Vite, RTL עברית, נתונים ב-localStorage (שכבת `src/store.js`), זמנים ולוח שנה חיים מ-Hebcal API. עטיפה ל-APK עם Capacitor.
- **הבא:** מעבר ל-Firebase (Auth OTP, Firestore, Storage, FCM) או שרת משלנו. מחליפים רק את `src/store.js`.

## 6. שלבים
1. MVP: הרשמה, סדר יום, זמנים, פרשה, מודעות, כיתות, לוח שנה, ספרים. ✔
2. Backend אמיתי + OTP SMS + התראות.
3. פאנל ניהול מלא, העלאת קבצים, אודיו.
4. תוספות.
